        <div class="col-span-full">
            <p class="mb-4">
                Memory Vault is geen opdracht van een klant, maar mijn eigen product: een digitale kluis waarmee mensen foto's, video's en persoonlijke berichten kunnen achterlaten voor dierbaren. Ik heb het idee, design en de volledige ontwikkeling zelf gedaan, van eerste concept tot een live SaaS-platform met betalende gebruikers.
            </p>
            <p class="mb-4">
                Het platform slaat herinneringen en &quot;Open When&quot;-berichten versleuteld op en levert ze pas af nadat vertrouwde contactpersonen het overlijden hebben bevestigd via een maandelijkse check-in. Zo blijft alles privé totdat het moment daar is.
            </p>
        </div>

        <div>
            <h3 class="text-2xl font-bold mb-4">Van eigen idee tot werkend platform</h3>
            <p class="mb-4">
                Naast de website bouwde ik de volledige productlogica: accountbeheer, versleutelde opslag voor tekst, foto&apos;s en video, een systeem voor vertrouwde contactpersonen en groepen, en de automatische check-in flow die bepaalt wanneer herinneringen worden vrijgegeven.
            </p>
            <p class="mb-4">
                Memory Vault is bewust <a class="text-primary font-medium hover:underline hover:opacity-80 transition-opacity" target="_blank" href="https://github.com/EgbertLudema/MemoryVault-Community-Edition">open source</a> te self-hosten, naast een gehost gratis- en betaald abonnement voor wie geen eigen server wil beheren.
            </p>
        </div>
